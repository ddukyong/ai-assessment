# 구글 시트 연결 방법

연결하지 않아도 앱은 작동합니다(각자 브라우저에만 저장). 연결하면 참여자의 설계안이 시트 한 줄씩 모입니다.

## 1. 시트와 서버 만들기
1. 구글 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 전부 붙여 넣습니다.
4. 맨 위 `COURSE_CODES`에 연수 코드를 정합니다. (예: `["ai2026"]`)
5. **배포 > 새 배포 > 유형: 웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 배포한 뒤 나오는 **웹 앱 URL**(`…/exec`로 끝남)을 복사합니다.

## 2. 앱에 주소 넣기
`index.html`의 스크립트 맨 위 두 줄을 바꿉니다.

```js
const SERVER_URL = "여기에 웹 앱 URL";
const COURSE_CODE_HINT = "ai2026";   // 연수 코드를 미리 채워 두고 싶을 때만
```

## 3. 참여자가 쓰는 방법
1. 오른쪽 위 **시트에 연결**을 누릅니다.
2. 연수 코드, 이름, 숫자 4자리 비밀번호를 넣습니다.
3. 그 뒤로는 단계를 옮길 때와 입력을 멈춘 지 20초 뒤에 자동으로 저장됩니다.

## 시트에 저장되는 것
- 저장 시각, 이름, 과목, 진행 단계, 점검 완료 수
- 단계별 확정본: 평가 요소, 발문, 자료, 조건, 채점기준, 예시답안, 채점기준 수정 사항, AI 활용 안내문, 피드백
- **학생 답안은 저장하지 않습니다.** 6단계에 붙여 넣은 학생 답안은 참여자의 브라우저에만 남습니다.

## Code.gs를 고친 뒤
**배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포**를 해야 반영됩니다. 주소는 그대로입니다.
